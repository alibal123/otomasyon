# Burak'ın örnek yazıları

(`.md` veya `.txt`, her biri ayrı dosya). Taslak üreticisi stili buradan öğrenir.

- Bu README stil örneği olarak kullanılmaz.
- Depo herkese açıksa buradaki yazılar da herkese açık olur; Burak'ın izniyle ekleyin.
